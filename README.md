# Buffer

![Release](https://img.shields.io/github/v/release/klaymm/Buffer) ![License](https://img.shields.io/github/license/klaymm/Buffer) ![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue) ![.NET Framework](https://img.shields.io/badge/.NET%20Framework-4.8-512bd4)

Небольшая программа для Windows, которая заменяет журнал буфера обмена по Win+V. Окно выглядит так же, как системное, но запоминает то, что Windows пропускает: большие скриншоты, файлы, а по желанию и пароли. История не пропадает после перезагрузки.

## Возможности

- **История по Win+V** - запись вставляется щелчком или клавишей Enter, сама запись остаётся на месте
- **То, что Windows пропускает** - большие скриншоты и файлы, а по желанию и пароли
- **Закрепление** - закреплённые записи не стираются кнопкой Clear all и переживают перезагрузку
- **Корзина** - удалённые записи открываются кнопкой "..."
- **Хранение на диске** - историю можно сохранять после перезагрузки, она лежит в зашифрованном виде
- **Настройки** - сочетание клавиш, язык и автозапуск

## Установка

Нужна Windows 10 или 11, .NET Framework 4.8 в них уже встроен.

1. Скачайте `Buffer.exe` со страницы [Releases](https://github.com/klaymm/Buffer/releases).
2. Запустите его. Установка не нужна, значок появится в трее.

Сборка из исходников (нужен .NET SDK 8 или новее):

```
dotnet build -c Release
```

Файл появится в `src\Buffer\bin\Release\Buffer.exe`.

## Использование

Win+V открывает историю. Щелчок по записи или Enter вставляет её туда, где стоит курсор, а сама запись остаётся на своём месте. Кнопка "..." открывает корзину, булавка закрепляет запись: закреплённое не стирается кнопкой Clear all и переживает перезагрузку.

Остальное в меню значка в трее:

- "Сохранять всё, даже после перезагрузки": запоминает всё подряд, включая пароли, и хранит историю на диске в зашифрованном виде.
- "Хранить все записи": без этой галочки хранятся 50 последних незакреплённых.
- "Запускать от имени администратора": нужно, если в Windows включён UAC ("Контроль учётных записей"), а вставлять надо в окна, открытые от имени администратора. Программа один раз спросит разрешение и дальше будет так запускаться.
- Сочетание клавиш, язык и автозапуск.

## Чего не умеет

Без режима администратора при включённом UAC не вставляет в окна администратора. Если программа не сообщает, где курсор, окно появится у указателя мыши.
