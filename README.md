# Buffer

Небольшая программа для Windows, которая заменяет журнал буфера обмена по Win+V. Окно выглядит так же, как системное, но запоминает то, что Windows пропускает: большие скриншоты, файлы, а по желанию и пароли.

Мне нужно было, чтобы история не пропадала после перезагрузки и чтобы в неё попадало всё скопированное.

## Как запустить

Нужна Windows 10 или 11, .NET Framework 4.8 в них уже встроен. Готовый Buffer.exe лежит в [Releases](https://github.com/klaymm/Buffer/releases).

Сборка из исходников (нужен .NET SDK 8 или новее):

```
dotnet build -c Release
```

Файл появится в `src\Buffer\bin\Release\Buffer.exe`.

## Как пользоваться

Win+V открывает историю. Щелчок по записи или Enter вставляет её туда, где стоит курсор, а сама запись остаётся на своём месте. Кнопка «...» открывает корзину, булавка закрепляет запись: закреплённое не стирается кнопкой Clear all и переживает перезагрузку.

Остальное в меню значка в трее:

- «Сохранять всё, даже после перезагрузки»: запоминает всё подряд, включая пароли, и хранит историю на диске в зашифрованном виде.
- «Хранить все записи»: без этой галочки хранятся 50 последних незакреплённых.
- «Запускать от имени администратора»: нужно, если в Windows включён UAC, а вставлять надо в окна, открытые от имени администратора. Программа один раз спросит разрешение и дальше будет так запускаться.
- Сочетание клавиш, язык и автозапуск.

## Чего не умеет

Без режима администратора при включённом UAC не вставляет в окна администратора. Если программа не сообщает, где курсор, окно появится у указателя мыши.
